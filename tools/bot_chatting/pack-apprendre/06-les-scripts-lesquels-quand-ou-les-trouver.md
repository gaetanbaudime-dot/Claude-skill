## Les scripts — lesquels, quand, où les trouver

Le texte mot à mot de chaque script vit dans le CRM (MyPulse / Infloww) — les scripts y
sont floutés une fois utilisés. Ici : à quoi ils servent et quand les déclencher.

- **KYC** : ouverture de relation — collecter prénom, âge, métier, situation, passions,
  fantasmes, sur plusieurs échanges, jamais en interrogatoire.
- **Tunnel de vente** : la séquence des contenus à paliers 7→112 €, à lancer uniquement
  sur un fan qualifié (voir les 4 piliers).
- **PostMedia** (~26 messages) : après l'envoi d'un media, entretenir l'excitation et
  amener le palier suivant.
- **Endurance** (~18 messages) : faire durer la session et monter l'intensité sans
  griller les étapes.
- **Négociation** (~64 messages, séquences n.0 / n.1 / n.2) : traiter les objections de
  prix par étapes — jamais de remise avant d'avoir déroulé la séquence.
- **Relance** (~21 messages) : réactiver un fan silencieux, par la conversation, jamais
  par un PPV à froid.
- **Second Round** (~4 messages) : relancer une deuxième vente dans la même session,
  juste après un achat.
- **Réel** (~3 messages) : ancrer un moment « authentique » qui renforce l'illusion de
  relation.
- Règle transverse : un script lancé trop tôt sur un fan mal qualifié est la première
  cause d'échec. Le terrain se prépare AVANT le script.

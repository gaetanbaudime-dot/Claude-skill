## Le tunnel de vente et les prix minimum

- Le tunnel maison enchaîne les contenus à prix croissants. Les paliers sont des
  **prix MINIMUM** : 7 € → 14 € → 28 € → 56 € → 84 € → 112 €. Cumulé, un tunnel complet
  fait ~301 € minimum.
- Ces prix sont des planchers **toujours dépassables vers le haut** selon le fan — jamais
  vers le bas. Le prix plancher est inviolable.
- Ancre la valeur AVANT d'annoncer le prix : un contenu « spécial », « exclusif »,
  « tourné cette semaine » vaut plus qu'un contenu standard proposé à froid.
- Le premier achat est le plus difficile : une fois que le fan a payé une fois, la
  barrière psychologique tombe et les achats suivants sont exponentiellement plus faciles.
- Un bon script est invisible : le fan doit avoir l'impression que l'idée d'acheter
  vient de lui.
